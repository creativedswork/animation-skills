# Character Acting

通过注意力、姿态和节奏表达角色意图。当前是待制作评测的知识草案；范围是身体表演，不承诺面部绑定、口型或细腻眼球动画。

## 确定角色在做什么

从任务中提取刺激、角色目标、内在变化和可观察动作。把“警觉”“疲惫”等形容词改写成可制作的行为，例如“听见身后动静，停止原动作，判断方向，再转身观察”。

读取已有角色、绑定、镜头和动作。检查头部、胸腔、手及眼球实际可控程度；没有眼球骨时用头部指向、身体朝向和停顿表达注意力，不要宣称做了眼神动画。

已有 Meshy 角色可直接使用；新资产由对应 provider 能力提供。使用已连接的 Blender MCP 或可运行的本地 Blender，检查实际 API 后另存制作工程。

读取 [performance.md](references/performance.md)，据此选择节奏和表演层次。涉及行走时组合 `character-body-mechanics`；涉及搬物或工具接触时由 `character-prop-interaction` 负责接触。其他 Skill 未安装时，至少保留脚部支撑及握持，说明尚缺少的专项能力。

## 设计表演

1. 写出少量意图明确的动作段，每段确定角色注意什么、决定什么、做什么。保留让观众读懂变化的时间。
2. 在主镜头下摆关键姿势。先检查剪影和头胸朝向，再做小幅细节；身体各部位不要互相抵消主要意图。
3. 按刺激与反应安排启动先后。眼、头、胸腔、骨盆不必同时运动，也不要机械套用固定延迟。
4. 让节奏具有对比：准备、行动与思考停顿有不同速度。停顿保留意图和支撑，避免全身冻结或无意义摇晃。
5. 只添加与情境相关的次要动作。一次明确呼吸或手部收紧可能比全身持续抖动更能表达状态。

## 在 Blender 中落实

保留原动作，将表演制作在明确的动作副本或分层轨道中。叠加 NLA 时检查混合模式、参考姿势和帧范围，避免把根位移、胸腔倾斜或关节旋转叠加两次。

做注视时定义世界空间目标及有效时段，检查头部关节范围。角色转身后重新计算相对朝向，防止头部持续拧向旧局部目标。让视线转移有目的，不随机抖动头骨。

用曲线表达呼吸和停顿时，保持变化少而连续。不要让所有部位同相位循环；疲劳、紧张和放松需要不同的身体选择。

## 完成依据

交付可编辑工程、指定导出物和原速视频。先不看任务文字观看片段，记录观众能否辨认刺激、意图变化与行动；再按任务判断是否准确。

在主镜头检查表演，在正侧面检查接触、穿插与关节连续性。重新导入导出物核对层叠与注视是否烘焙完整。把“动作技术上成立”与“表演清楚、有节制”分别报告；未获得外部评价时不要自报品味通过。
