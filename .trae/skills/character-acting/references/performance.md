# 身体表演的选择

## 注意力与反应

让刺激具有可定位的方向或时刻。小刺激可以先转头确认，大威胁可能让整个身体立即反应；不要把“眼先、头后、身体再后”当成所有情况的固定公式。

设计警觉时，先减少与目标无关的运动，让姿态聚焦；判断之后才决定靠近、转身或退开。无休止左右摆头通常会削弱注意力。若角色没有眼球控制，头部停留方向和胸腔姿态承担更多表达。

## 疲惫与负担

疲惫不等于周期乘以常数。考虑以下变化中哪些符合情境：

- 推进不足：步幅变短、离地高度减小，但保留足够净空。
- 恢复变慢：停步后胸腔较晚稳定，呼吸有必要的停留。
- 意愿与能力冲突：角色想继续前进，身体需要多一次准备。
- 局部支撑：手扶大腿或支撑物，前提是绑定和接触确实能实现。

选择少量一致的变化，不把耷肩、弯腰、摇晃、拖脚和颤抖全部叠加。高频腿抖会被读成绑定问题，除非剧情明确要求并且支撑仍成立。

## 节奏与姿势

先在时间轴上标出“观众应该看懂的时刻”，再连接姿势。不同动作段可以使用不同间距；让快速变化与较长停留形成层次。持有姿势时允许一处有目的的微动，其余部分稳定支撑。

非对称应该有原因：注意力方向、负重、支撑腿或角色习惯。任意给左右关键帧错开几帧，可能只会破坏接触。左右不一致不自动等于自然。

## 校准品味

以任务风格为尺度。写实片段偏重克制和动机连续，风格化片段允许夸张的蓄力与姿态，但都要让关键变化读得清楚。

评价时分别写出：意图是否读得到、最有效的动作选择、哪一处过量或含混。证据指向原速视频的时刻和可见姿态，不以“更自然”“更高级”代替观察。

评价多个版本时先隐藏版本标签、随机观看顺序，再做对照。若评价者知道哪版用了新 Skill，记录这一条件；单个修正版更好不能证明新 Skill 独立制作能力已经提高。
