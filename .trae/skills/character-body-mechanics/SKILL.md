# Character Body Mechanics

制作有重量、接触可信、轮廓清楚的双足身体动作。当前是待制作评测的知识草案，未包含经过 case 验证的动作资产。

## 输入与制作条件

读取已有角色、绑定、参考动作、目标时长和交付格式。检查实际骨骼名称、静止姿势、面向、单位、地面高度和关节自由度，建立当前角色的骨骼映射；不要假定 Meshy 骨架具有控制器、脚趾骨或统一命名。

已有 Meshy 产物时直接使用。需要新角色或绑定时，先确认已配置的 Meshy MCP 能力及生成授权；资源生成由对应 provider 能力负责。本 Skill 从可用角色开始制作动作。

优先使用已连接的 Blender MCP 操作场景。未连接时可使用本地 Blender 与 `bpy`；若两者均不可用，明确缺少制作环境。修改前保留原始工程，将制作结果另存。

## 按任务读取

- 步行、转向、起步和停止：读取 [gait.md](references/gait.md)。
- 坐下、起立和支撑面转移：读取 [sit-stand.md](references/sit-stand.md)。
- 用情绪改变身体动作时，可组合 `character-acting`；本 Skill 仍负责脚步和承重。物体重量与持握关系由 `character-prop-interaction` 主负责。

## 先决定支撑与运动

1. 标出动作阶段及各阶段的支撑：左脚、右脚、双脚、座面。确定何时接触、承重、卸载和离开。
2. 选择根节点运动方式。世界空间行走保留位移；原地循环需要明确预期移动速度。不要同时在根骨与角色对象上重复累加位移。
3. 先摆关键姿势，以胸腔、骨盆、头和支撑脚表现方向及力量。检查重心与支撑关系；快速移动允许重心投影短暂离开支撑区，后续脚步必须接住身体。
4. 确定节奏后再补中间姿势。先做骨盆轨迹和支撑脚，再做摆动脚、胸腔和手臂；手臂不能替代身体本身的重量表达。

## 在 Blender 中落实

- 支撑脚需要稳定世界位置时，用脚控制目标或临时 IK；让膝盖极向量沿角色腿平面连续移动。不要在膝盖接近伸直时让极向量穿过求解平面。
- 接触不等于整只脚永久焊死。按脚跟、脚掌、脚尖的实际滚动确定当前固定点；没有脚趾骨时用脚骨与骨盆共同表现有限滚动，保留能力限制。
- 在父级运动下设置世界空间接触目标。向骨骼写关键帧前，将目标转换到该骨骼的父级和静止姿势空间；不要将世界坐标直接写入 `pose_bone.location`。
- 四元数插值前保持相邻关键帧同半球；欧拉角跨越 ±180° 时处理角度连续性。不要以逐帧加噪声表现自然。
- 拍点式 blocking 可用 Constant；转入连续运动后逐段选择插值。承重平台与触地瞬间不能被自动 Bezier 手柄拉出滑动或穿地。
- 导出需要变形骨动画时，在副本上按目标帧率烘焙约束后的视觉变换。Blender Action、slot 和导出选项随版本变化，先检查当前 API；不要依靠旧版固定调用。

## 制作品味

让动作具有一个清楚的主要方向。骨盆控制身体的行进和重量，胸腔与头允许有限滞后；把次要运动留给动作需要的地方。用支撑时间、步幅和重心变化表达性格，避免给所有关节叠加同频正弦波。

保持轮廓可读：脚步不要在主镜头中长期完全重叠，肘部不要无意夹死。风格化可改变幅度与节奏，但要保留足够的接触与恢复关系，让观众读懂力量。

## 完成依据

交付可编辑 `.blend`、任务要求的导出文件和原速视频。检查主镜头、正面及侧面；定位脚底滑动、膝盖翻转、骨盆跳变、穿插与动作接缝。循环任务检查末帧到首帧的姿势与速度，非循环任务检查停稳阶段。

重新导入导出物，核对时长、根位移、脚底接触和约束烘焙结果。报告看过的视图、可定位的问题及尚未验证部分；文件能导出不代表动作已经自然。
