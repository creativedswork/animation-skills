# Character Prop Interaction

把角色与道具作为一个接触和受力系统制作。当前知识是待制作评测的草案，未附已验证动作资产。

## 读取条件

读取角色绑定、道具形状、预期重量、接触点、任务节奏与镜头。检查单位、骨骼轴向、关节范围和手指能力；粗骨架没有手指时，以掌部接触及腕部朝向表达握持，并说明近景限制。

已有 Meshy 产物可直接进入 Blender。新资产生成交给已配置且获授权的 provider；不要在制作动作时擅自替换固定评测输入。

通过可用 Blender MCP 或本地 Blender 与 `bpy` 操作，先检查版本和 API。另存制作工程。缺少 Blender 执行环境时说明尚不能完成实际作品。

## 按任务读取

- 搬起、搬运、放下：读取 [lifting.md](references/lifting.md)。
- 斧击、锤击及其他持握工具撞击：读取 [tool-impact.md](references/tool-impact.md)。
- 明显依赖行走时可组合 `character-body-mechanics`，由它补充步态；本 Skill 主负责道具轨迹、握持和重量转移。

## 确定控制关系

为动作标出接近、接触、施力、共同运动、卸载、松手各阶段。写明每阶段谁驱动谁：

| 状态 | 常见控制选择 |
| --- | --- |
| 道具在地面或台面上 | 固定道具，手靠近接触点 |
| 单手持轻工具 | 手驱动工具，工具保持固定局部握持关系 |
| 双手持物或工具 | 道具或主手建立主轨迹，另一只手跟随接触目标 |
| 放下后 | 道具重新稳定在支撑面，手再松开 |

不要让双手与道具互相设约束形成循环依赖。选择一个明确的主控制者；另一只手在满足握持的同时允许肩肘自然调整。

## 制作

1. 先摆接触姿势及力量最大的姿势，确认肘部净空、道具轮廓和手腕朝向。
2. 设计道具在世界空间中的轨迹，再让骨盆、胸腔和脚步支持该轨迹。重物改变全身动作，不能只有手臂负重。
3. 在实际接触帧建立父子或约束关系。切换前匹配世界矩阵和约束逆矩阵，确保接触帧前后连续。
4. 完成主要重量后再处理肩部、头部及衣物的次要跟随，避免所有部位同时启动、同时停止。
5. 导出副本烘焙可视变换，包含道具自身动画。确认目标格式是否支持当前约束；通常不能直接依赖 Blender 约束在 glTF 中执行。

## 完成依据

交付可编辑工程、指定导出物和原速视频。观看斜前方全身镜头及握持近景，定位手掌穿物、约束切换跳变、道具无支撑漂浮、双手距离变化和冲击前后的受力顺序。

重新导入导出物，核对角色与道具同步、道具路径和接触关系。重量表现与握持正确性分别说明；手没有离开道具，不代表动作已经有力量。
