# 搬起、搬运与放下

## 让重量发生在全身

先确定物体的重量感、抓握位置与角色能力。轻物允许手臂直接带起；重物需要接近身体、建立支撑并用腿与髋参与。物体离躯干越远，表现同样重量所需的身体补偿通常越明显。

不要把“重”简化成所有曲线统一放慢。重量常通过以下关系被读到：

- 接触之后有建立力量的阶段，物体没有在手碰到之前自行起飞。
- 身体发力与物体离地有可读关系，起动受限，稳定阶段仍有控制。
- 搬运时步幅和转向受到负担影响，停止前有制动与重量回收。
- 放下时先让支撑面接收重量，再释放双手。

## 双手与箱体

在道具局部空间标出左右抓握点，沿道具轨迹求出手的世界目标。根据肩宽、臂长和箱体尺寸调整肘部朝向；不要为保留固定手势拉长手臂。

搬起宽箱时，箱体会遮住躯干。用侧面检查腹部净空、手掌接触及重心，用主镜头检查观众是否仍能看出发力。若抓握点不可达，改变角色接近位置或合理抓法，而非移动接触点让手在表面滑行。

## 放下

把落点设计进动作轨迹。接近台面时减速，让箱底与台面建立稳定接触；身体允许一次小幅重量回收。箱体稳定后再松手并退开，不能在尚未接触时撤掉承重姿势。

## 制作判断

| 可见不足 | 首先检查的制作关系 |
| --- | --- |
| 像端着空盒子 | 物体离身距离、发力准备、骨盆参与及搬运步幅 |
| 肩膀耸起且肘部僵硬 | 抓握点可达性、道具高度、主控制者是否相互冲突 |
| 起放瞬间跳动 | 父级切换世界姿势是否匹配、约束影响是否有连续过渡 |
| 物体很稳但角色在晃 | 身体补偿是否与步伐和负载有关，而非独立正弦运动 |

这些是选择制作方法的线索，不是已经通过评测的自动诊断规则。
